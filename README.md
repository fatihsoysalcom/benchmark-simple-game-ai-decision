# Benchmark Simple Game AI Decision

This example demonstrates a simple game AI decision-making process and benchmarks its performance. It simulates an enemy AI evaluating its environment and making a choice over many iterations, measuring the total execution time to highlight potential CPU impact, similar to how large language models might generate benchmark code for game AI.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
